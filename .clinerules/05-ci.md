# CI topology

PR/main cross-platform workflow contains only:
- repository-checks
- linux
- macos
- linux-sanitizers

Windows is a separate workflow. It runs on every push to main, and on a pull
request only when `.github/workflows/windows-post-merge.yml` changes. It has
no workflow_dispatch trigger. The pinned OpenCV 4.1/4.10/5.0 matrix is manual-only.
